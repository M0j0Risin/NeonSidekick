These are the app's built-in themes: every file under assets\themes, one folder per category, is compiled in, and the default is collider. To change one for yourself, write it out with /theme export <name> [new-name] into %USERPROFILE%\.neonsidekick\themes, edit it and pick it with /theme; a file there named like a built-in replaces it. A theme file stands alone: it sets all fifteen colors itself. bauhaus, deco, glitch, inkwash, nixie, opal, stainedglass, temper, ukiyoe and vinyl use a 14-stop gradient, which puts each letter of the 27-cell title on its own stop. The solid themes repeat one color, so the title is a single color and the rule a solid bar. This page is written by tools\ThemeAtlas.cs.
