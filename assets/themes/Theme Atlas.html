These themes ship in the repo under assets\themes, one folder per category, with the ten built-ins exported under built-in. To use one, copy its file into %USERPROFILE%\.neonsidekick\themes itself (the app reads only the top of that folder) and pick it with /theme. A file named like a built-in replaces that built-in, so a file from built-in can be copied in as it is, or edited. bauhaus, deco, glitch, inkwash, nixie, opal, stainedglass, temper, ukiyoe and vinyl use a 14-stop gradient, which puts each letter of the 27-cell title on its own stop. The solid themes repeat one colour, so the title is a single colour and the rule a solid bar.
